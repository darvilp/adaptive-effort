# Adaptive Effort 0.1.3

This release gives Fast, Balanced, and Deep distinct worker-effort policies. Fast now uses Low implementation and routine reviews, Medium debugging, and no automatic High recovery. Balanced retains Low implementation, Medium routine reviews and debugging, and evidence-gated High recovery. Deep starts every implementation and same-thread repair at Medium, with High debugging and routine reviews.

The release also removes the preliminary implementation work-category decision. The selected mode now determines implementation effort directly.

Superpowers remains an external prerequisite. Portal scan, publication, installed-cache pickup, fresh-task discovery, and live-routing proof are not claimed by this repository release.
