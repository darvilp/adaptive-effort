# Security

Adaptive Effort is an instruction-only plugin with local diagnostic scripts.

It does not:

- collect telemetry
- require API keys
- contact a remote orchestration service
- install dependencies
- alter Codex configuration
- install Superpowers
- download executables

Subagents inherit the parent Codex sandbox and approval policy. Review the plugin source before enabling write-capable workflows.

Report security issues through GitHub's private vulnerability reporting for this repository. Do not open a public issue for an undisclosed vulnerability.
