## 0.1.1 — 2026-08-29

- Clarified the ownership split between Superpowers workflow decisions and Adaptive Effort routing decisions.
- Added an ephemeral compact trace with separate worker and gate outcomes, semantic failure fingerprints, true escalation counting, and required closeout.
- Added a separate one-shot mechanical correction and explicit carried-boundary results.
- Added manual scenarios for planned reviews, corrective transitions, mechanical stops, bounded missing-context continuation, and deferred boundaries.


## 0.1.0 — 2026-08-22

- Initial community-marketplace plugin snapshot.
- Added one implicit Adaptive Effort skill.
- Added fast, balanced, and deep effort policies.
- Added compact implementer, debugger, recovery, and reviewer handoffs.
- Added bounded low → medium → high escalation.
- Added static doctor and canonical policy scripts.
- Added marketplace, manifest, policy, and doctor tests.
- Restricted release packaging to an explicit marketplace-repository allowlist and promoted the full design to canonical documentation.
- Changed cheap repair to a same-thread follow-up that retains the original worker effort.
- Removed unsupported agent-type routing fields from the policy and documentation.
- Narrowed implicit activation to active Superpowers implementation workflows and added a concise routing trace.
- Added surface-tagged Windows/WSL diagnostics with `BLOCKED`, `STATIC_READY`, and `RUNTIME_VERIFIED` readiness.
- Made live setup smoke testing explicit instead of automatic.
